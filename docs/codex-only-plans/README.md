# Codex Only Plans

本目录为 `Codex` 专用的计划与执行记录目录。

## 作用
- 存放 Codex 在进入“先规划后执行”流程时生成的 Markdown 计划文档。
- 这些文档用于帮助 Codex 组织复杂任务、记录执行步骤、沉淀验证方案和风险说明。

## 适用范围
- 适用于需要正式计划的任务。
- 例如：跨多个模块的改动、涉及多阶段执行的任务、需要先明确验证策略的任务。

## 非适用范围
- 简单、小范围、低风险的修改不强制要求写计划文档。

## 目录约定
- 本目录是 `Codex only` 工作目录。
- `Claude Code` 运行时不必参考本目录，也不要求遵守本目录中的计划文档。

## 文件命名
- 默认命名格式：`YYYY-MM-DD-<topic>-plan.md`

## 建议结构
- 背景与目标
- 约束条件
- 分步骤执行计划
- 验证方式
- 风险与待确认项
